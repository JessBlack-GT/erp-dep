## Introducción

Este manual guía al usuario final del sistema ERP-SYSTEM.

## Primer Acceso

1. Abra la aplicación en su navegador o dispositivo móvil
2. Si es la primera vez, registre una cuenta
3. Complete el perfil de su cuenta
4. Comience a usar los módulos disponibles

## Consejos de Seguridad

1. **Use contraseñas seguras**: Combinación de letras, números y símbolos
2. **No comparta su contraseña**: Cada usuario debe tener credenciales únicas
3. **Cierre sesión**: Si usa un dispositivo compartido
4. **Reporte actividades sospechosas**: Contacte al administrador
5. **Mantenga su perfil actualizado**: Para recibir notificaciones correctas

## Solución de Problemas

### No puedo iniciar sesión
- Verifique su email y contraseña
- Use "Olvidé mi contraseña" si la olvidó
- Contacte al administrador si el problema persiste

### La aplicación no carga
- Verifique su conexión a Internet
- Actualice la aplicación a la última versión
- Limpie la caché del navegador

### Un módulo no responde
- Espere unos segundos
- Recargue la página
- Si persiste, contacte al administrador
